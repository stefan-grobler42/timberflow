Clear Browser Cache - Millennium ERP

Your browser has cached the old version. Try these methods to see the updated ERP system:

Method 1: Hard Refresh

Windows/Linux: Ctrl + F5 or Ctrl + Shift + R

Mac: Cmd + Shift + R

Method 2: Developer Tools

1. Open Developer Tools: F12

2. Right-click the refresh button

3. Select "Empty Cache and Hard Reload"

Method 3: Private/Incognito Window

Chrome: Ctrl + Shift + N

Firefox: Ctrl + Shift + P

Open the ERP URL in the private window

Method 4: Clear All Cache

Chrome: Settings → Privacy → Clear browsing data → Cached images and files

Firefox: Options → Privacy → Clear Data → Cached Web Content

Expected Result: You should see the Millennium Roofing ERP with blue navbar, grey background, and working stock management.
